## OperatorRoleAccount

Scoped maintenance permission mask for delegated access control. The supported bits are address-list management, snapshots, health refresh, policy simulation, liveness refresh, and scoped-pause management.

**Seeds:**
```
[b"operator_role", treasury, operator]
```

## SessionKeyAccount

Scoped, expiring delegated key for temporary access grants.

**Seeds:**
```
[b"session_key", treasury, session_key]
```

## AddressListAccount

Allow/deny recipient list for address-based access control.

**Seeds:**
```
[b"address_list", treasury]
```

## ExternalLivenessAccount

Dependency freshness timestamps for external service monitoring.

**Seeds:**
```
[b"external_liveness", treasury]
```
