`aura-core` returns Anchor errors from the `AuraCoreError` enum, starting at code **6000**. Domain-layer `TreasuryError`s are mapped to these at the instruction boundary.

<Callout title="Error code range">
  All aura-core errors are in the **6000-6199** range. Errors below 6000 are Anchor framework errors.
</Callout>

## Common Patterns

### Error Code Format
```
6XXX | ErrorName | Description
```

### Handling Errors

Most errors include contextual information about what triggered them. Always check:
- The specific instruction that failed
- Account states involved
- Policy rules that were violated
- Resource limits that were exceeded
