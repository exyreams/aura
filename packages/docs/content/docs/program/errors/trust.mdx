## Trust Envelope

| Code | Name | Trigger |
|---|---|---|
| 6102 | `TrustLockdownActive` | Treasury is in Lockdown; no proposals may be submitted. <New /> |
| 6103 | `InvalidTrustPolicy` | Trust policy thresholds are not monotonic or multipliers exceed 1×. <New /> |
| 6104 | `TrustRestoreUnauthorized` | Caller is not the owner or a registered guardian. <New /> |

## Ownership Handover

| Code | Name | Trigger |
|---|---|---|
| 6105 | `SuccessorNotNominated` | `execute_ownership_handover` called with no pending nomination. <New /> |
| 6106 | `OwnershipHandoverTimelockActive` | Handover timelock (48 h) has not elapsed. <New /> |
| 6110 | `UnauthorizedHandover` | Caller is not authorized to nominate or execute an ownership handover. <New /> |

## Custody Recovery

| Code | Name | Trigger |
|---|---|---|
| 6097 | `NoRecoveryDestination` | `break_glass_recover` called but no recovery address registered for the chain. <New /> |
| 6098 | `RecoveryTimelockActive` | Attempting to change a recovery destination before its lock window expires. <New /> |
| 6099 | `RecoveryPreconditionNotMet` | Treasury is not in emergency shutdown, or the 1-hour post-shutdown activation window has not elapsed. <New /> |
| 6100 | `RecoveryDestinationImmutable` | Attempting to change a recovery destination while an emergency shutdown is active. <New /> |
| 6101 | `UnauthorizedRecovery` | Caller is not authorized to initiate a recovery operation. <New /> |
