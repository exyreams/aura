`aura-core` returns Anchor errors from the `AuraCoreError` enum, starting at code **6000**. Domain-layer
`TreasuryError`s are mapped to these at the instruction boundary. Errors marked <New /> were added with the
latest instructions.

## Authorization

| Code | Name | Trigger |
|---|---|---|
| 6000 | `UnauthorizedAi` | Caller is not the registered AI authority. |
| 6001 | `UnauthorizedOwner` | Caller is not the treasury owner. |
| 6002 | `UnauthorizedGuardian` | Caller is not a registered guardian. |
| 6003 | `UnauthorizedExecutor` | Caller may not finalize/execute. |
| 6044 | `OperatorRoleMissing` | No operator role for the required permission. |
| 6045 | `OperatorRoleExpired` | Operator role is expired or revoked. |

## Policy versioning & canary

| Code | Name | Trigger |
|---|---|---|
| 6121 | `NoCandidatePolicy` | `promote_canary`/`discard_canary` called with no active candidate. <New /> |
| 6122 | `CanaryAlreadyActive` | A candidate is already being trialed for this treasury. <New /> |
| 6123 | `CanarySampleFloorNotMet` | `promote_canary` called before the candidate reached its sample floor. <New /> |

A rollback to a version not present in the history ring, or one whose supplied
candidate does not hash to the recorded fingerprint, returns `UnknownPolicyVersion` (6074); a
candidate that fails coherence validation returns `InvalidTemplateConfig` (6072).
